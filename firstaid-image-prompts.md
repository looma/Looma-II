# First Aid images — AI generation prompts (ALL sections)

Illustrations for the Health tab. **136 slots total, but only ~121 unique images
to generate** — 15 captions repeat between a topic's Emergency and Learn views,
so those are marked **↺ REUSE** below (one file serves both; no need to make them
twice). Save each image to the exact path shown. The page auto-detects the file
(`.png`/`.webp`/`.jpg`/`.jpeg`) and swaps the caption text for your image;
missing files just keep showing the caption.

Recommended: square 1:1, 1024x1024.

## Using Gemini (Gemini Advanced / Pro) — no per-image cost, included in your plan

1. Open **gemini.google.com** and start a new chat.
2. Paste the **STYLE PREAMBLE + first Subject line** and let it generate the image.
3. **Lock the style:** once you have one you like, for every next image say:
   *"Same exact style, palette, and character look as before. New subject: …"*
   and paste the next subject line. Gemini keeps the set consistent this way.
4. Download each result and rename it to the exact filename shown before saving
   into `images/health/`.
5. Do one whole topic per chat so its steps share the same look.
6. **Skip anything marked ↺ REUSE** — that file already exists from the step named.

## STYLE PREAMBLE — paste in front of EVERY subject line

> Flat modern vector illustration, clean rounded shapes, soft cel shading, bold
> readable forms. Limited warm palette with a clear red safety accent (#d93a3a)
> and a blue accent (#1d6fb8) on a plain off-white background. No text, no words,
> no logos. Single centered subject with generous margin, square 1:1 composition.
> Culturally appropriate rural Nepal / South-Asian people with warm brown skin
> tones and simple everyday clothing. Calm, non-graphic, child-friendly
> educational tone - never gory or frightening. Subject:
